星河 AI 学习社团手册
本手册为 AI Agent Learning 编写的虚构教学样本。社团、人员安排、设备型号和数值均用于练习，不代表真实组织或产品。

第一章：课程与项目
星河 AI 学习社团采用六周项目制。每个项目由三名成员合作完成，每周安排两小时讨论。学习目标是理解模型调用、提示词、对话记忆、文档检索和工具调用之间的关系。
第一阶段为第一周到第二周，成员学习 Python 环境、API 调用和提示词模板，并完成一个命令行问答程序。第二阶段为第三周到第四周，成员加载社团手册，将文本分块并构建向量索引，完成可追溯来源的 PDF 问答。第三阶段为第五周到第六周，成员增加工具调用、错误处理和离线测试，整理项目说明并演示成果。
每组设置资料员、开发者和评审员三个角色。资料员准备可公开使用的文档，开发者实现主要功能，评审员核对回答是否被原文支持。角色每两周轮换一次，保证每位成员都能练习不同任务。

第二章：文档问答实验
文档问答实验先计算文件内容的 MD5 标识，再按页加载 PDF。文本默认每块二百个字符，相邻块重叠二十个字符。向量索引按文件标识存储，避免不同文档互相混淆；修改分块设置或嵌入模型后应重新建立索引。
收到问题时，系统可以结合对话历史改写检索问题。它先召回十条候选片段，再过滤重复和过短片段，用语言模型打分，最终保留四条证据。回答必须包含证据编号，证据同时记录来源和页码。没有找到依据时，应说明手册未提供信息，不应编造答案。
连续提问示例是“社团项目周期是多久？”和“它的第二阶段要完成什么？”。第二个问题中的“它”指社团项目，检索前应结合第一轮问题明确这一指代。原始问题仍用于最终回答，改写问题仅用于检索。

第三章：设备与评估
社团使用三种虚构教学机器人。Aurora-2 配有二十四个传感器，适合室内导航；Aurora-4 配有四十八个传感器，适合路线规划；Lumen-1 配有十二个传感器，适合语音交互。设备数据仅用于演示关键词检索与语义检索的差异。
每个项目准备十二道评估题，其中八道可以在手册中找到答案，两道需要理解连续对话，两道在手册中没有答案。评审员逐题检查证据页码、引用编号和回答内容。对于无法回答的问题，正确拒绝编造也算通过。
运行联网实验前应配置自己的模型 API 密钥。密钥保存在本地环境文件中，不放入源码或截图。单元测试只验证本地逻辑，使用替身模型和临时目录，不调用付费 API，也不要求访问互联网。
